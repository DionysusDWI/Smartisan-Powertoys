# 01 · TNT GO 无线版硬件参数

> 来源：锤子商城技术规格、天极参数页、百度百科「扩展本」词条、社区拆解与评测
> 整理时间：2026-09-09

## 产品定位

- 名称：Smartisan TNT go（扩展本）
- 发布：2020-10-20，与坚果 R2 同场发布
- 形态：需搭配坚果手机使用的便携式智能显示器；**本身无独立 CPU / 存储**（官方定位），依赖手机启动 TNT OS 2.0
- 版本：有线版 / 无线版；**无线版额外标配 Smartisan 智能手写笔**

## 屏幕

| 项目 | 参数 |
|---|---|
| 尺寸 | 12 英寸 LCD IPS，全贴合 |
| 分辨率 | **2160×1440（2K）** |
| 比例 | 3:2 |
| 刷新率 | 60Hz |
| 亮度 | 380 尼特（典型值） |
| 对比度 | 1000:1（典型值） |
| 触控 | 十点触控 |

> ⚠ 中关村在线参数页写作 2560×1440，但 2560×1440 为 16:9，与官方 3:2 矛盾；以官方与天极的 **2160×1440** 为准。

## 电池与充电

- 容量：**10160mAh**
- 充电：35W 快充，支持 PD 3.0 / QC 3.0（需原装充电器与数据线）
- 反向充电：可为连接的手机供电
- 标配：55W 电源适配器

## 接口

- **USB-C 视频输入口**（全功能）：支持 2K/60fps 视频输入、供电、数据传输
- **USB-C 充电口**：仅供电（**不支持视频输入**）
- 底部触点接口：连接磁吸键盘
- 按键：电源键、音量键

## 音频 / 摄像头

- 立体声双扬声器 + 双 SmartPA
- 双麦克风阵列：AI 拾音降噪、定向拾音（正前方）/ 全向拾音
- 前置 500 万像素摄像头，f/2.0，68.4° 视场角，支持人脸识别解锁

## 键盘与手写笔

- 键盘：78 键全尺寸超薄键盘，剪刀脚结构，键程 1.25mm；大面积玻璃触控板支持五点触控；磁吸触点连接，无需配对
- 手写笔（**无线版标配**）：4096 级压感，笔尖直径 1.5mm，续航约 10 小时，USB-C 充电，磁吸收纳（不支持磁吸充电）

## 尺寸与重量

- 机身：275.5 × 190.8 × 7.2mm
- 重量：主机约 619g（部分评测实测 639g）；键盘支架约 167g；整机约 806g
- 无线版套装（含键盘、手写笔）：约 1.0 ~ 1.16kg

## 无线连接（无线版核心差异）

- Wi-Fi 6 低延迟投屏 + TNT Link 无线技术（乐播 × 新石实验室合作）
- 投屏延迟最低约 **50ms**（上一代约 150ms）
- 连接流程：亮屏 → 蓝牙发现手机 → 手机开热点 → TNT GO 连热点接收投屏
- **首次使用需有线连接一次坚果手机激活配对**
- 官方仅支持搭配坚果 R2 使用（社区已通过破解绕过）

## 价格与版本（发布时）

- 无线版 2999 元（含手写笔）；有线版 1999 元
- 大满足套装（坚果 R2 + TNT go）：有线版 6999 元 / 无线版 8299 元
- 后续清仓：有线版约 1199~1500 元，无线版约 1900~2000 元

## 兼容性备忘

- 有线模式：PC / 掌机（USB 3.1 Gen1 以上数据口）可直连；Windows 下触控可用；iPad 可显示 + 触控；**Mac 仅显示不可触控**
- HDMI 设备（Xbox / PS5 / Switch）需 HDMI 转 Type-C 转接器；Switch 一线连不支持激活主机模式
- 有线模式下 TNT GO 屏幕内容完全由外部设备渲染，其内置安卓系统不参与画面
