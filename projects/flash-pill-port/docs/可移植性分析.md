# 闪念胶囊（IdeaPills）提取与可移植性分析

> 源设备：Smartisan 锤子 OS（Android 10 / SDK29 / arm64，Build SMARTISAN/aries）。
> 结论先行：**该软件几乎不可能在原封不动地在其他机型上原生运行**——它深度耦合 Smartisan OS 框架、私有权限、系统签名与桌面/语音/侧边栏生态，且为 32 位原生库。

## 二、结构与依赖分析

### 1) 没有独立启动入口（关键点）
- `launchable-activity`=0，无法从桌面"打开"该应用。
- 组件为：多个 `receiver`（`SystemIntentReceiver`、`CreationNotificationLimitReceiver` 等）+ 大量被系统内部跳转的 `activity`（`CopyActivity`、`RemindBubbleShowActivity`、`IdeaPillsActivity`、`ShareMainActivity`…）+ `provider`（`IdeaPillsCallProvider`）。
- 即：它是**被 Smartisan 桌面/侧边栏(一步)/语音(sara)/长按唤起**的后台胶囊功能，必须由 Smartisan 系统组件触发。

### 2) 强依赖 Smartisan 框架类（`smartisanos.jar`）
dex 中直接引用非 Android 标准框架类，例如：
`Lsmartisanos/api/ActivityManagerSmt;`、`Lsmartisanos/api/ViewSmt$OnForceTouchListener;`、`Lsmartisanos/widget/ShadowButton;`、`Lsmartisanos/app/tracker/Agent;`、`Lsmartisanos/util/...`
> 这些类只存在于 Smartisan 的 `smartisanos.jar` 中。其他 ROM 无此类 → 运行即 `NoClassDefFoundError`。

### 3) 依赖 Smartisan 私有权限/生态
声明并需要以下 vendor 权限（其他 ROM 未定义，无法授予）：
`smartisanos.recorder.*`、`com.smartisanos.sidebar.permission.IDEA_PILLS_SYNC`、`smartisanos.expandservice.data_sync`、`com.smartisan.permission.READ_CLOUDSYNC`、`com.smartisan.permission.ACCOUNT_CENTER`、`com.smartisanos.calendar.permission.ADD_EVENT`、`com.smartisanos.mail.PROVIDER_CALL`。
并申请大量 **signature|privileged** 系统权限：`READ_FRAME_BUFFER`、`MANAGE_APP_TOKENS`、`INTERNAL_SYSTEM_WINDOW`、`INJECT_EVENTS`、`KILL_UID`、`SET_ORIENTATION` 等——仅系统签名/priv-app 可获。

### 4) 生态耦合
- 依赖 **Com.smartisanos.sidebar（一步）+ expandservice**（胶囊同步/拖拽）、**com.smartisanos.sara（语音录入）**、recorder recorder provider、cloudsync/账户中心、日历。
- 采用 bytedance 插件架构（`com.bytedance.ideapillspluginimpl` / `ideapillsapi`），宿主依赖进一步加深。

## 三、能否在其他机型运行？

### 结论：**不能以原包直接运行（基本不可行）**
原因汇总：
1. **框架缺失**：`smartisanos.jar` 的类不在其他 ROM → 必崩溃。
2. **权限缺失/签名受限**：vendor 权限在其他 ROM 无定义且无法授权；系统签名权限仅平台签名 app 可得；作为普通用户应用安装会因签名/权限校验失败。
3. **无入口**：没有可启动入口，缺 Smartisan 桌面/一步/语音作为触发宿主。
4. **32 位原生库**：无 arm64；在纯 64 位设备（无 32 位兼容库）上直接失败。
5. **生态整合**：胶囊的创建/气泡/同步深度依赖 Smartisan 的桌面、侧边栏、语音、云同步等，缺一不可。

### 要"跑起来"需要什么（成本高、不稳定）
- 目标设备需 **root / 可刷机**，且内置 `smartisanos.jar`（或把其中被引用的类补进应用）、补齐对应 vendor 权限、用平台签名重签、并安置为 **priv-app**。
- 同时要有 Smartisan 的 **launcher(page)/sidebar(一步)/sara(语音)/recorder/cloudsync** 协同，这基本等于移植整条 Smartisan 安全链/框架，工程量≈还原一个小型 SmartisanOS 子系统。
- 即便勉强启动，闪念胶囊的核心交互（长按唤起、胶囊气泡、拖拽分享、云端同步）在非 Smartisan 生态下也**无法正常工作**。

## 四、建议
- 若目标只是**使用"闪念/快速笔记"类功能**，更现实的是采用通用方案（如系统级速记/悬浮胶囊/语音转文字 App），而非移植本私有组件。
- 若目标是**二次开发/研究**（分析胶囊交互、气泡、提醒逻辑），本 APK 已提取（含完整 dex），可用 jadx/apktool 反编译研究其 `ideapills.view.Bubble*`、`BubbleManager`、`remind/`、`sync/share/` 等模块。此用途下此包具有价值。

- 原始路径 `/system/priv-app/IdeaPills/IdeaPills.apk`；伴生组件 `com.smartisanos.sara`（VoiceAssistant.apk，50MB）未随包。

## 附：应用外依赖清单（除专属按键外）

> 除 Smartisan 的专属按键/手势触发外，闪念胶囊对外部组件/服务的依赖如下。

### 1) Smartisan 框架类（`smartisanos.jar`，系统框架层）
- `Lsmartisanos/api/*`：`LayoutParamsSmt`、`WindowManagerSmt`、`ViewRootImplSmt`、`SettingsSmt`、`ViewSmt`、`DragEventSmt`、`ClipboardManagerSmt`、`ApplicationInfoSmt`、`VibratorSmt`、`ViewSmt$OnForceTouchListener`
- `Lsmartisanos/widget/*`：`TitleBar`、`SmartisanDatePicker*`、`ListContentItem*`、`SettingItemSwitch`、`ShadowButton`
- `Lsmartisanos/util/*`：`MimeUtils`、`SidebarHelper`、`SidebarUtils$TextDragBuilder`、`GaussianBlurUtils`、`NameAvatarController`、`config/Features`
- `Lsmartisanos/os/RemoteCallback*`、`Lsmartisanos/view/PressGestureDetector`(+BoomDelegate)、`Lsmartisanos/app/SmartisanProgressDialog`、`Lsmartisanos/cloudsync/util/*`、`Lsmartisan/widget/calendar/CalendarView`

### 2) Smartisan 系统应用 / 服务（独立组件）
| 组件 | 用途 |
| --- | --- |
| **com.smartisanos.sara（语音助手）** | 语音录入闪光：绑定 `com.smartisanos.sara.bubble.BubbleActivity` / `GlobalBubbleCreateActivity`；用 `VoiceAssistantInterface`、`getVoiceSearchLaunchRecognizer`、`setVoiceEncryptKey`、`checkIsVoiceAvailable`、`getVoiceMaxResults`；动作 `smartisan.action.VIEW_MULTI_VOICE_INPUT_RECORD` |
| **com.smartisanos.sidebar（一步/侧边栏）** | 拖拽创建：`com.smartisanos.sidebar`、`getSidebarModeState`、`SidebarHelper`/`SidebarUtils$TextDragBuilder`、权限 `IDEA_PILLS_SYNC` |

### 3) 系统/敏感权限（签名级，需 priv-app + 平台签名）
`READ_FRAME_BUFFER`、`MANAGE_APP_TOKENS`、`INTERNAL_SYSTEM_WINDOW`、`INJECT_EVENTS`、`KILL_UID`、`MANAGE_APP_TOKENS`、`SYSTEM_ALERT_WINDOW`、`SET_ORIENTATION`、`DISABLE_KEYGUARD` 等，以及 `READ/WRITE_EXTERNAL_STORAGE`、`ACCESS_ALL_EXTERNAL_STORAGE`、`getWindowManagerService`（window bound）。

### 4) 第三方(bytedance)宿主依赖
- `com.bytedance.ideapillspluginimpl` / `com.bytedance.ideapillsapi`（插件实现与 API）
- `com.bytedance.retrofit2`、`com.ss.android.IAppLogService`、`com.ss.android.article`（头条系底层日志/网络/宿主）

- `BOOT_COMPLETED` 开机广播；`SEND`/`SEND_MULTIPLE`/`COPY_TEXT` 分享目标；`MediaBrowserServiceCompat`、`JobIntentService`/`JobServiceEngine`、`NotificationSideChannelService`、`USAGE_VOICE_COMMUNICATION` 等。

> **结论**：闪念胶囊的"应用外依赖"非常重——它同时依赖 **Smartisan 框架 jar（系统层）**、**sara 语音 / sidebar 一步 / recorder / cloudsync / 账户中心 / 日历 / 邮箱 / 锁屏 / launcher** 等一整套 Smartisan 系统组件、以及**大量签名级系统权限**与 **bytedance 插件宿主**。这正是它无法在其他机型原生运行的根本原因。
