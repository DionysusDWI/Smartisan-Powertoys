# 闪念胶囊复刻 · 技术方案（v0.1）

> 项目：`projects/flash-pill-port/`
> 目标：在小米 17 Pro Max（HyperOS 3 / Android 16 / 不 root）上复刻闪念胶囊核心体验
> 整理时间：2026-09-09

## 1. 需求定义

### 必须实现（用户明确）

1. **侧边栏启动**：屏幕边缘把手，拖拽 / 点击唤起
2. **悬浮窗 + 可打开界面**：悬浮气泡快速记录 + 完整列表界面
3. **语音转写**：接入硅基流动（SiliconFlow）/ DashScope 实时语音
4. **文本记录**：快速输入
5. **本地存储**：不依赖云（个人使用）

### 原版交互参考（来自 `docs/DESIGN_FROM_VIDEO.md` 逐帧反推）

- 触发：**屏幕右缘左划**（原版还有长按 Home / 耳机线控中键）
- 按住录音 → 屏幕底部弹出胶囊气泡（带实时波形）→ 松手保存
- 保存音频本体，文字事后转写（存音频 → 转写）
- 收起态：**屏幕右缘一个半透明小把手**，胶囊按时间 / 分类堆在右缘，可悬浮任意 App 之上
- 展开态：5 分类色标（便签蓝 / 重要红 / 待办橙 / 待发送绿 / 灵感紫）+ 转写文字 + 波形回放 + 操作栏 + 自动网络搜索

## 3. 总体架构

### 3.1 模块划分（借鉴 flash-capsule，按需裁剪）

```
:app                  # 组装、导航、入口
:core:model           # Capsule / Attachment / RawCapture
:core:database        # Room
:core:data            # Repository + FileStore
:feature:capture      # 捕获浮层（录音 / 文字）
:feature:inbox        # 胶囊列表 / 详情
:feature:sidebar      # 侧边栏把手 + 悬浮气泡（本项目重点）
:transcribe           # Transcriber 接口 + SiliconFlow / DashScope 实现
:sinks                # 分享 / 日历 / 便签导出
```

### 3.2 数据模型（沿用 flash-capsule，微调）

```kotlin
data class Capsule(
    val id: String,
    val createdAt: Long,
    val updatedAt: Long,
    val text: String = "",
    val audioPath: String? = null,
    val status: CapsuleStatus,      // CAPTURED / TRANSCRIBING / TRANSCRIBED
    val colorTag: ColorTag?,        // 便签 / 重要 / 待办 / 待发送 / 灵感
    val tags: List<String> = emptyList(),
    val source: String,
    val reminderAt: Long? = null,
    val pinned: Boolean = false,
)
```

### 3.3 核心接口

- `CaptureSource`（入口）→ `CaptureRepository.ingest()`
- `Transcriber`：`SiliconFlowTranscriber` / `DashScopeTranscriber`（可切换）
- `Sink`（输出：分享 / 日历 / 便签）

## 4. 关键技术方案

### 4.1 侧边栏把手（核心差异点）

- 实现：`TYPE_APPLICATION_OVERLAY` + `WindowManager`，`FLAG_NOT_FOCUSABLE | FLAG_NOT_TOUCH_MODAL`
- 形态：屏幕右缘半透明竖条（宽 8~12dp、高 120~200dp），可上下拖动、自动吸附边缘
- 交互：点击 → 展开胶囊面板；拖拽 → 移动 / 换边
- **冲突处理**：与系统返回手势（左右边缘滑动）冲突 → 把手避开手势热区（距边缘 ≥16dp），或双击 / 长按触发（参考 flash-capsule v0.3.1「侧边把手加宽避开返回手势」）
- 常驻成本：overlay 本身极低；**进程被杀后把手消失** → 需保活策略（见 4.4）

### 4.2 悬浮气泡（记录态）

- 按住把手（或面板内按钮）→ 录音 → 屏幕底部弹出气泡（带实时波形）→ 松手保存
- 气泡用 Compose / 自绘，全程非位图
- 可悬浮在任意 App 之上（overlay）

### 4.3 语音转写

| 方案 | 形态 | 优点 | 缺点 | 建议 |
|---|---|---|---|---|
| **SiliconFlow** | HTTP 一次性（音频 → 文本） | 简单、便宜 | 非实时 | **MVP 首选** |
| **DashScope Paraformer-realtime** | WebSocket 流式 | 实时、边说边出字 | 接入复杂 | 迭代 |
| 系统 STT | `SpeechRecognizer` | 零成本、免 key | 精度 / 隐私 | 兜底 |
| 端上 Whisper | whisper.cpp | 离线私密 | 体积大、耗电 | 可选 |

- MVP：`AudioRecord` 录音 → WAV/Opus → SiliconFlow ASR → 写入 `Capsule.text`
- 迭代：DashScope WebSocket 实时流式（`AudioRecord` → PCM 帧 → WebSocket）
- 参考：DashScope 文档 `help.aliyun.com/zh/model-studio/websocket-for-paraformer-real-time-service`；接入示例 `github.com/mikuh/dashscope-realtime`

### 4.4 后台保活（小米 HyperOS 适配重点）

- 录音 / 转写期间：前台服务（`FOREGROUND_SERVICE_MICROPHONE`）+ 通知
- 侧边栏常驻：前台服务（`specialUse`）或接受「被杀后消失」
- 必须引导用户：
  1. 悬浮窗权限（设置 → 应用 → 其他权限 → 显示在其他应用上层）
  2. 自启动白名单
  3. 省电策略 → 无限制
  4. 锁屏显示 / 后台弹出界面

### 4.5 权限清单

| 权限 | 用途 | 备注 |
|---|---|---|
| `SYSTEM_ALERT_WINDOW` | 悬浮窗 | 用户手动授权 |
| `RECORD_AUDIO` | 录音 | 运行时申请 |
| `FOREGROUND_SERVICE` / `_MICROPHONE` / `_SPECIAL_USE` | 前台服务 | Android 14+ |
| `POST_NOTIFICATIONS` | 通知 | Android 13+ |
| `INTERNET` | 语音转写 | |

## 6. 风险清单

| 风险 | 影响 | 缓解 |
|---|---|---|
| 小米后台杀进程 | 侧边栏把手消失 | 前台服务 + 自启动白名单引导 |
| 边缘手势冲突 | 把手难触发 | 避开热区 / 双击触发 / 位置可调 |
| 悬浮窗权限被拒 | 功能不可用 | 引导页 + 检测 |
| 语音 API 配额 / 网络 | 转写失败 | 本地队列重试 + 系统 STT 兜底 |
| Android 16 16KB page | 原生库问题 | 纯云端方案可规避 |
