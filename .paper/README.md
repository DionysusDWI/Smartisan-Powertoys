## 迭代更新约定

### 版本号规则

- **主版本**(v2.0):结论发生**实质性修正**(如某条判定被推翻)
- **次版本**(v1.1):新增章节、补充数据、修正细节
- **每次修改**都必须:
  1. 更新文档头部的 `版本` 与 `更新` 日期
  2. 在 [CHANGELOG.md](CHANGELOG.md) 追加一条记录(日期 / 文档 / 变更内容 / 依据)
  3. 若结论被推翻,**保留原判定并标注勘误**(不直接删除),避免重复踩坑

### 勘误写法

```markdown
> ⚠️ **勘误(v1.1)**:早前判定「X」,实测修正为「Y」。
> 依据:<实测数据 / 反编译证据 / 来源 URL>
```

### 数据来源标注

| 标记 | 含义 |
|---|---|
| **实测** | 真机 adb / dmesg / dumpsys 直接取得 |
| **反编译** | smali / jadx / aapt2 从二进制提取 |
| **交接包** | `handover/TNT_Handover/`(手机侧一手实测) |
| **网络** | 外部来源(URL 归档在 `.ref/Search-Results/`) |
| **推断** | 无直接证据,基于旁证的合理推测 —— **必须显式标注** |
