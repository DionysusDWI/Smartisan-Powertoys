## ⚠️ 先说清楚这个版本是什么

**这是开发预览版，不是稳定版。** 它在一部**真实的坚果 Pro 3 ＋ TNT GO** 上开发、
并且每个功能都有实机取证；但它**没有经过广泛机型验证**，
接口与行为**可能随时变动**。

> ★ 特别说明：安装包是 **debug 签名**。目的是让人**能装、能读、能改**，
> 不是让人拿来日常依赖。

---

## 装之前请先读这三条

### 1️⃣ 装完还有**一步 adb 干不了**的活

Smartisan 的悬浮窗有**两道门**，脚本只能过第一道：

| 门 | 怎么过 |
|---|---|
| ① Android `SYSTEM_ALERT_WINDOW` appop | ✅ `adb` 可自动授 |
| ② **Smartisan 自己的悬浮窗授权** | ⛔ **只能人点**：`手机管理 → 权限管理 → Smartisan Powertoys → 悬浮窗` |

**只过 ① 不过 ② 的症状极具迷惑性**：窗口加得上、bounds 也对、
**logcat 一个错都没有 —— 但永远不显示。**

### 2️⃣ 「TNT GO 亮度」需要手动开**无障碍**

`设置 → 无障碍 → Smartisan Powertoys`。这是系统硬要求（`adb` 授不了）。

### 3️⃣ 「实时字幕」需要**你自己的** API Key

本应用**不含任何 Key**，也不会向作者回传数据。
去阿里云百炼（DashScope）申请一个，填进应用设置即可。
**不填只是该模块不工作**，不影响别的模块。

## ★ 关于「性能模式」：请不要期待它是万能加速

这一点值得单独说，因为它的实测结论**反直觉**：

| 场景 | 实测 |
|---|---|
| **AV1 软解**（无硬件解码器，纯 CPU） | ★ **+35.8%**，而且**方差被压掉**（20–32 fps → 42.2–42.7 fps）＝ **从卡到不卡** |
| **H.264 硬解 / Web / 多任务** | ★ **测不出收益**（CPU 92% 空闲；瓶颈在专用硬解器与磁盘 IO） |
| **空载** | ⚠️ **纯浪费**（+60 mA，约 +34%） |

⇒ **只在「持续 CPU 重负载」下开它**，而且用完就关
（应用内有自动过期机制）。

★ 另有一条被修正过的旧结论也留在这里：早期用**合成基准**测出的
「+75%」**不能外推到真实场景** —— 那正是上表第二行「测不出收益」的由来。

## 已知限制

* **只在坚果 Pro 3（DT1901A）＋ TNT GO 上验证过**，其它机型不保证
* **TNT GO 相关模块依赖该型号屏幕的私有 AT 协议**，换屏即失效
* **debug 签名**，不适合日常长期使用
* 文档与代码注释**大部分是中文**
* 「实时字幕」依赖第三方云服务，其可用性不由本项目保证

## 安装

```bash
adb install -r powertoys-debug.apk
```

然后按上面「装之前请先读这三条」做那几步人工授权。

**校验**：本版 APK 的 SHA-256 见 Release 页附件说明。

---

## 从源码构建

```bash
bash scripts/build.sh mode-all
bash scripts/deploy.sh mode-all
```

需要 **JDK 17 ＋ Android SDK**。`toolchain/`（便携工具链）**没有入库**，
请自备或改 `scripts/env.sh`。
